# SkyVista implementation plan

1. Reference-led responsive homepage, navigation, destinations, offer and honest review area.
2. Deterministic simulated provider, validated search, multi-leg flight selection, seats and baggage.
3. Supabase cookie authentication, profiles, persistent bookings and RLS migration.
4. Server-priced bookings, Paystack test initialization, verification and signed webhooks, atomic idempotent payment recording, PDF.
5. Role-protected admin inventory and content management.
6. Lint, TypeScript, build, unit and browser functional checks. External credentials required for integration verification.
